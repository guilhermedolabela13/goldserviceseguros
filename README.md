# Gold Service Seguros — Site Piloto

Piloto HTML estático para apresentação ao Victor em 2026-05-21.

## Estrutura
- `index.html` — Home
- `quem-somos.html` — Quem Somos
- `seja-parceiro.html` — Seja Parceiro
- `contato.html` — Contato
- `assets/css/styles.css` — Design system + componentes
- `assets/img/` — Logos cropadas

## Como visualizar
Abrir `index.html` direto no navegador (file://) ou servir local:

```bash
python -m http.server 8000
```

Depois abrir http://localhost:8000
